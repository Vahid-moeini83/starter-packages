# Project Starters

A monorepo containing starter packages for frontend and backend projects.

## Packages

- **frontend-starter**: CLI tool to initialize frontend projects with skills, context, and MCP configurations
- **backend-starter**: CLI tool to initialize backend projects with skills, context, and MCP configurations

## Development

```bash
# Install dependencies
npm install

# Link packages locally for testing
cd packages/frontend-starter && npm link
cd ../backend-starter && npm link
```
